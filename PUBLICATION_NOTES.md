The repository contains a fresh export of an August 8, 2026 research folder. Source repository history and unrelated project files were not imported.

- All **54 named source documents** are retained, with relocated paths and the edits below. The original ranking instructions were adapted for standalone use.

- This publication adds a README, methodology description, score CSVs, an aggregation script and generated report, an audit, and scoped license notices.

## Privacy review and cleanup

The review combined scans across every source file with inspection of flagged contexts, headers, bylines, author comments, and judge reports. It checked for email addresses, phone numbers, local machine paths, URLs, credentials and key/token patterns, personal-name candidates, and internal workflow references. No email addresses, phone numbers, credentials, or local machine paths were found. Fictional character names and public framework references were retained.

Removed or generalized items include internal coordinator names, device/workflow labels, task handoff fields, an internal application bug note, a private project label in one judge heading, account-spend commentary, and a filename reference to source notes outside this export. Personal initials were removed from the original human-sheet and human-ballot filenames. John's first name remains.

Judge identities and recorded model configurations remain in the file names, answer key, and methodology because they are part of the experiment. Creative decisions, scores, critical opinions, and erroneous model rationales were preserved. The human ballot title now describes “scores and comments from chat” rather than claiming the entire chat excerpt is verbatim after an unrelated bug note was removed.

Privacy cleanup changes metadata in some creative files. The original whole-file word counts are preserved in [entries.csv](entries.csv) and used for historical correlations; current published-file counts can differ. The only creative-content metadata reference changed within a blinded entry was the unavailable source-notes filename in I; operational handoff fields were also removed from L. Story prose is unchanged.

The historical report is linked to a new [audit](RESULTS_AUDIT.md) instead of silently rewriting its original interpretations. CSV scores follow the printed ballots, including known mistakes in those ballots. Rights notices distinguish MIT-licensed research from reserved creative expression wherever it appears.
